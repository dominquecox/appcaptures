# AppCaptures project instructions

## Pull request readiness — standing rule from Dom, 2026-10-24

- Never open draft pull requests.
- Every pull request must be complete, verified, and opened ready for review. If the work is incomplete, keep it off a pull request.
- This owner instruction supersedes earlier AppCaptures/localbrain guidance requiring draft PRs.
- Ready for review does not authorize merging or deployment; follow Dom's current task scope for those actions.
